# Blog posts

Each featured essay has a page at `/writing/<slug>/`. To publish the full text
on this site, add a Markdown file here named after the slug:

- `taste-is-the-last-moat.md`
- `fast-is-a-moat.md`
- `designops-debt.md`

Supported: `##`/`###` headings, paragraphs, `-` and `1.` lists, `>` quotes,
`---` rules, `![alt](url)` images on their own line, **bold**, *italic*,
`code` and [links](https://example.com). Don't repeat the title; the page
adds it. Until a file exists, the page shows the summary and links to Medium.
